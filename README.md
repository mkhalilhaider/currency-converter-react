# 🔐 Password Generator App (React)

This is my fourth React project — a responsive and user-friendly Currency Converter built using custom React hooks and Free live exchange rate API by **fawazahmed0**

Convert currencies in real-time with just a few clicks!


## 🚀 Features

- Creating and using custom React hooks

- Working with controlled components

- Handling side effects with useEffect

- Prop drilling and component structure

- Styling interactive UI using Tailwind CSS

- API integration and data transformation

___
## 🧠 What I Learned

✅ How to build and use custom hooks (like useCurrencyInfo)

✅ Deep dive into useEffect, API calls, and dependency arrays

✅ Controlled components and form handling in React

✅ State management for multiple values (amount, from, to, convertedAmount)

✅ Real-time UI updates and logic-based rendering

✅ Clean design using Tailwind CSS

✅ How to structure code cleanly for reusability (like reusable InputBox component)

## How to Run Locally
1. Clone the repo:
    ```bash
    git clone https://github.com/mkhalilhaider/currency-converter-react
    ```
2. Install dependencies:
    ```bash
    npm install
    ```
3. Start the development server:
    ```bash
    npm run dev
    ```
